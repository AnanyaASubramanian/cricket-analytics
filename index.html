How it was built

Data, definitions and checks

  • Data: Cricsheet ball-by-ball JSON for the IPL (2008–2026) and men's T20 internationals (2005–2026), loaded into DuckDB by a Python script into two tables: matches and deliveries.
  • Definitions live in one SQL view so every query agrees: balls faced exclude wides, legal balls exclude wides and no-balls, byes and leg byes aren't charged to the bowler, run-outs aren't credited to the bowler, super overs are excluded.
  • Phases: powerplay overs 1–6, middle 7–15, death 16–20.
  • Validation: runs and wickets for 15 innings across 8 landmark matches, including four World Cup finals, match the official scorecards exactly, and every ball's runs reconcile.
  • Caveat: T20Is include associate nations, whose matches grew sharply after 2019. Cricsheet withholds matches involving Afghanistan's men's team.
